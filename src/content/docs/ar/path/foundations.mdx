قبل الـ CTI لازم تكون فاهم تقنياً كفاية إنك تتابع الهجمة نفسها، مش بس تقرا وصفها. كل جزء تحت ليه كورس واحد. خلّصه من أوله لآخره وبعدين كمّل.

لو إنت شغال أصلاً في SOC أو IT أو Pentesting، عدّي على الخطوة دي بسرعة وكمّل الناقص بس.

## 1. Networking

<Course title="CompTIA Network+ (N10-009) full video course" url="https://www.professormesser.com/?p=632187" by="Professor Messer" cost="free" time="87 videos · ~13 hours">
منهج Network+ كله ببلاش. اتفرج عليه كله بالترتيب.
</Course>

<Course title="CompTIA Network+ شرح عربي" url="https://www.youtube.com/results?search_query=Sameh+Ramadan+CompTIA+Network%2B" by="Sameh Ramadan" cost="free" time="27 lessons · ~15.5 hours" arabic>
كورس Network+ كامل بالعامية المصرية على قناة Sameh Ramadan Tech على يوتيوب.
</Course>

**بعد الكورس**، اتأكد إنك فاهم مواضيع الـ Networking اللي الـ CTI بيعتمد عليها أكتر. هتقابلها تاني في الخطوات الجاية:

- الـ DNS tunneling والـ fast flux DNS والـ domain generation algorithms (DGA).
- الـ Domain fronting.
- الـ TLS fingerprinting: JA3 وJA4 وJARM.
- أنماط اتصال الـ C2.

**تمرين:** التمارين اللي على [Malware-Traffic-Analysis.net](https://www.malware-traffic-analysis.net/training-exercises.html) عبارة عن PCAPs حقيقية لإصابات ومعاها الحلول. استخدم Wireshark.

## في الشغل

في شغل الـ CTI مش هتظبط routers. هتقرا PCAPs جاية لك من الـ incident response، وتحدد إذا كان domain شكله fast flux أو DGA، وتقرا PowerShell من script خبيث، وتكتب script صغير بدل ما تعمل 200 lookup بإيدك. وده اللي الخطوة دي معمولة عشانه.

## المشروع: IOC enrichment tool

اعمل tool بـ Python تاخد IP أو domain أو hash، وتتأكد إنه صحيح، وتكلم الـ APIs بتاعة VirusTotal وAbuseIPDB، وتطلع report بصيغة JSON. ارفعها على GitHub ومعاها README.

## تقدر تنقل للخطوة الجاية لما

- تقدر تشرح إيه اللي بيحصل، protocol بـ protocol، لما تفتح موقع.
- تقدر تتابع TCP أو HTTP stream في PCAP.
- تعرف Windows وLinux بيحطوا الـ processes والـ persistence والـ logs فين.
- الـ enrichment tool بتاعتك شغالة.
