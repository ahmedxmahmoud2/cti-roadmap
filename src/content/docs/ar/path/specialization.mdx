دلوقتي اختار مجال أو اتنين وادخل فيهم بعمق، بدل ما تعرف حاجة صغيرة عن كل حاجة.

## في الشغل

عملياً، تخصصك غالباً بيتحدد باللي فريقك ناقصه. اختار المجال اللي بتستمتع بالشغل فيه واللي فريقك أو السوق محتاج حد فيه.

## A. Advanced adversary infrastructure hunting

اكتشاف الـ C2 infrastructure، والـ Cobalt Strike fingerprinting، وBrute Ratel C4 وSliver وMythic، وسلاسل الـ redirectors، والـ TLS fingerprinting، والـ infrastructure clustering، وتحليل أنماط الـ hosting، ودورة حياة infrastructure الخصم.

## B. Advanced malware research

الـ reverse engineering، والـ assembly (x86/x64)، والـ Windows internals، والـ API hooking، والـ process injection، واستخراج الـ malware config، والتحليل التشفيري، وتقنيات الـ anti-analysis، وتصنيف الـ malware families.

## C. Advanced threat hunting

بناء الـ hypotheses، والـ behavioural analytics، وإعادة بناء الـ attack chain، والـ detection gap analysis، والـ SIEM queries المتقدمة، وتحليل الـ EDR telemetry، والـ memory forensics، والـ network forensics، والـ threat-informed detection.

## D. Vulnerability and exploit intelligence

تحليل الـ CVEs، والـ CVSS، والـ EPSS، والـ CISA KEV، وتوفر الـ exploits، وتحليل الـ proof-of-concept، والـ exploit chaining، واتجاهات الاستغلال، وتتبع الـ zero-days، وربط الـ vulnerabilities بالـ actors.

## E. Cloud and identity threat intelligence

هجمات Entra ID والـ Active Directory، والـ threat landscape بتاع AWS وAzure، والـ cloud persistence، والـ token theft، والـ OAuth abuse، والهجمات المبنية على الـ identity، والـ C2 infrastructure على الـ cloud.

## كورسات مدفوعة تستاهل تفكر فيها

متبدأش كذا واحد مع بعض. خلّي عندك track أساسي واحد، والباقي tracks مساعدة.

- **SANS FOR578 (Cyber Threat Intelligence):** من أقوى كورسات الـ CTI الموجودة. غالي، فهو واقعي أكتر لو الشركة هي اللي بتدفع.
- **SANS FOR508:** قوي في الـ DFIR وإعادة بناء الـ incidents، بس مش بديل لتدريب الـ CTI.
