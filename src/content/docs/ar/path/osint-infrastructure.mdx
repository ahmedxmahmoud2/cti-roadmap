## في الشغل

مهمة عادية: الـ SOC يبعتلك domain أو IP مشبوه من alert. تعمله enrichment، وتعمل pivot منه، وتحدد إذا كان جزء من infrastructure أكبر، وترجّعلهم indicators مرتبطة ومعاها context، مش مجرد blocklist.

## هتتعلم إيه

### الـ OSINT التقني

- **Domains:** التسجيل، والـ registrar، والـ nameservers، وتاريخ الـ DNS، والـ MX records، والـ SPF/DKIM/DMARC، والـ subdomains.
- **IPs:** الـ ASN، والـ BGP، والـ hosting providers، والـ reputation، وحدود الـ geolocation.
- **Certificates:** الـ Certificate Transparency logs، وتحليل الـ SAN، وإعادة استخدام الـ certificates.

**الأدوات:** Shodan وCensys وFOFA وVirusTotal وurlscan.io وcrt.sh وSecurityTrails.

### الـ Infrastructure pivoting

إنك تلاقي domain واحد مشبوه مش كفاية. اتعلم تعمل pivot:

- Domain → IP → domains تانية على نفس الـ IP.
- Domain → certificate → domains مرتبطة.
- IP → ASN والـ hosting provider.
- الـ favicon hash أو الـ HTTP headers أو الـ TLS fingerprint (JARM وJA3/JA4) → servers شبهها.

## المشروع: infrastructure hunting

اختار APT campaign منشورة وابدأ من domain أو IP واحد معروف. اعمل pivot عن طريق الـ passive DNS والـ certificates والـ hosting، وارسم infrastructure graph، وعلّم أنهي روابط مؤكدة وأنهي محتملة. واكتب النتيجة باللي اتعلمته في الخطوة 2.

## تقدر تنقل للخطوة الجاية لما

- تقدر تبدأ من indicator واحد وتلاقي infrastructure مرتبطة لوحدك.
- كل رابط في الـ graph بتاعك ليه دليل وconfidence واضح.
