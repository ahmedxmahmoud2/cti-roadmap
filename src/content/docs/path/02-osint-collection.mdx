## What you will learn

### OSINT fundamentals

Passive and active reconnaissance, search engine operators, advanced Google dorking, public code repositories, Certificate Transparency, WHOIS, DNS intelligence, historical and passive DNS, internet asset discovery.

### Technical OSINT

- **Domain intelligence:** registration, registrar analysis, nameserver correlation, DNS history, MX records, SPF/DKIM/DMARC, subdomain enumeration.
- **IP intelligence:** ASN, BGP, the limits of geolocation, hosting providers, IP reputation, historical IP relationships.
- **Certificate intelligence:** Certificate Transparency logs, SAN analysis, issuer patterns, certificate reuse, certificate fingerprinting.

### Infrastructure discovery

**Tools:** Shodan, Censys, FOFA, VirusTotal, urlscan.io, crt.sh, SecurityTrails.

### Infrastructure pivoting

Finding one suspicious domain is not enough. Learn to pivot:

- Domain → IP.
- IP → other hosted domains.
- Domain → SSL certificate → related domains.
- IP → ASN / hosting provider.
- Malware sample → C2 infrastructure.
- Favicon → similar web services.
- HTTP headers → infrastructure similarities.
- TLS fingerprint → related servers.

**Advanced:** JARM, JA3/JA4, favicon hashing, HTTP response fingerprinting, Cobalt Strike infrastructure detection, redirector identification, C2 server fingerprinting, infrastructure clustering.

## Project: APT infrastructure hunting

Pick a published APT campaign and start from one known domain or IP. Then:

- Run a passive DNS investigation.
- Look for related certificates.
- Analyse the hosting infrastructure.
- Search for similar domains.
- Compare HTTP and TLS characteristics.
- Draw an infrastructure graph.
- Mark which links are confirmed and which are possible.
- Assess your confidence in each link.

**Deliverable:** an infrastructure intelligence report with evidence for every pivot.

## You are ready to move on when

- Starting from one indicator, you can find related infrastructure on your own.
- Every link in your graph has a stated confidence and the evidence behind it.
