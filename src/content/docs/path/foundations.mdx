Before CTI you need enough technical understanding to follow the attack itself, not just read a description of it. Each area below has one course. Take it end to end, then move on.

If you already work in SOC, IT or pentesting, skim this step and only fill the gaps.

## 1. Networking

<Course title="CompTIA Network+ (N10-009) full video course" url="https://www.professormesser.com/?p=632187" by="Professor Messer" cost="free" time="87 videos · ~13 hours">
The whole Network+ syllabus, free. Watch all of it, in order.
</Course>

<Course title="CompTIA Network+ شرح عربي" url="https://www.youtube.com/results?search_query=Sameh+Ramadan+CompTIA+Network%2B" by="Sameh Ramadan" cost="free" time="27 lessons · ~15.5 hours" arabic>
The full Network+ course explained in Egyptian Arabic on the Sameh Ramadan Tech YouTube channel.
</Course>

**After the course,** make sure you understand the networking topics CTI relies on most. You will meet them again in later steps:

- DNS tunneling, fast flux DNS and domain generation algorithms (DGA).
- Domain fronting.
- TLS fingerprinting: JA3, JA4, JARM.
- C2 communication patterns.

**Practice:** the exercises on [Malware-Traffic-Analysis.net](https://www.malware-traffic-analysis.net/training-exercises.html) are real infection PCAPs with answers. Use Wireshark.

## 4. Scripting

<Course title="Automate the Boring Stuff with Python" url="https://automatetheboringstuff.com/" by="Al Sweigart" cost="free">
Free to read online. Read the first half, then the chapters on web scraping, JSON and CSV.

You do not need to be a software engineer. You need to call an API, parse JSON and automate your own repetitive work.

## On the job

You will not configure routers in a CTI job. You will read PCAPs that incident response hands you, decide whether a domain looks like fast flux or a DGA, read PowerShell from a malicious script, and write a small script instead of doing 200 lookups by hand. That is what this step is for.

## Project: IOC enrichment tool

Build a Python tool that takes an IP, domain or hash, validates it, queries the VirusTotal and AbuseIPDB APIs, and outputs a JSON report. Put it on GitHub with a README.

## You are ready to move on when

- You can explain what happens, protocol by protocol, when you open a website.
- You can follow a TCP or HTTP stream in a PCAP.
- You know where Windows and Linux keep processes, persistence and logs.
- Your enrichment tool works.
