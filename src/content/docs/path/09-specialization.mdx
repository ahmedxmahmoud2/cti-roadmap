Now pick one or two areas and go deep, instead of knowing a little about everything.

## A. Advanced adversary infrastructure hunting

C2 infrastructure discovery, Cobalt Strike fingerprinting, Brute Ratel C4, Sliver, Mythic, redirector chains, TLS fingerprinting, infrastructure clustering, hosting pattern analysis, the adversary infrastructure lifecycle.

## B. Advanced malware research

Reverse engineering, assembly (x86/x64), Windows internals, API hooking, process injection, malware config extraction, cryptographic analysis, anti-analysis techniques, malware family clustering.

## C. Advanced threat hunting

Hypothesis development, behavioural analytics, attack chain reconstruction, detection gap analysis, advanced SIEM queries, EDR telemetry analysis, memory forensics, network forensics, threat-informed detection.

## D. Vulnerability and exploit intelligence

CVE analysis, CVSS, EPSS, CISA KEV, exploit availability, proof-of-concept analysis, exploit chaining, exploitation trends, zero-day tracking, linking vulnerabilities to actors.

## E. Cloud and identity threat intelligence

Entra ID and Active Directory attacks, the AWS and Azure threat landscapes, cloud persistence, token theft, OAuth abuse, identity-based attacks, cloud C2 infrastructure.

## Paid courses worth considering

Do not start several at once. Keep one main track and treat the rest as supporting tracks.

- **SANS FOR578 (Cyber Threat Intelligence):** one of the strongest CTI courses available. Expensive, so realistic mainly when an employer pays.
- **SANS FOR508:** strong for DFIR and incident reconstruction, but not a replacement for CTI training.
