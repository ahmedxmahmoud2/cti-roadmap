Before CTI you need enough technical understanding to follow the attack itself, not just read a description of it. Do not study networking topic by topic. Take a full course end to end, then focus on the parts CTI analysts use every day.

## 1. Networking

Study a complete networking course from start to finish.

<Course title="CompTIA Network+ (N10-009) full video course" url="https://www.professormesser.com/?p=632187" by="Professor Messer" cost="free" time="87 videos · ~13 hours">
The whole Network+ syllabus, free on YouTube and his site. Watch all of it, in order.
</Course>

**Then, the networking topics CTI relies on most** (you will meet them again in steps 2 and 4):

- DNS tunneling, fast flux DNS and domain generation algorithms (DGA).
- Domain fronting.
- TLS fingerprinting: JA3, JA4, JARM.
- HTTP traffic fingerprinting.
- C2 communication patterns.

**Tools:** Wireshark, tcpdump, Zeek, NetworkMiner.

**Practice:** work through the exercises on [Malware-Traffic-Analysis.net](https://www.malware-traffic-analysis.net/training-exercises.html). They are real infection PCAPs with answers.

## 3. Operating systems

<Course title="Pre Security learning path" url="https://tryhackme.com/path/outline/presecurity" by="TryHackMe" cost="freemium">
Hands-on Linux and Windows fundamentals in the browser, plus networking and web basics.
</Course>

Make sure you understand:

- **Windows:** processes and threads, the registry, services and scheduled tasks, event logs, PowerShell, WMI, DLL loading, authentication, Active Directory basics.
- **Linux:** the filesystem, processes, permissions, systemd, cron jobs, SSH, Bash, logs, persistence mechanisms.

## 4. Programming and scripting

You do not need to be a software engineer, but you must be able to automate your own work.

<Course title="Automate the Boring Stuff with Python" url="https://automatetheboringstuff.com/" by="Al Sweigart" cost="free">
A beginner Python book that is free to read online. Read the first half, then the chapters on web scraping, JSON and CSV.
</Course>

Focus on: requests, BeautifulSoup, pandas, JSON parsing, regex, REST APIs, Git, and the basics of PowerShell and Bash.

## Project: IOC enrichment tool

Build a Python tool that:

- Takes an IP, domain or hash and validates it.
- Queries the VirusTotal and AbuseIPDB APIs.
- Normalises the results.
- Outputs a JSON report.

Put it on GitHub with a README.

## You are ready to move on when

- You can explain what happens, protocol by protocol, when you open a website.
- You can follow a TCP or HTTP stream in a PCAP.
- You know where Windows and Linux keep processes, persistence and logs.
- Your enrichment tool works.
