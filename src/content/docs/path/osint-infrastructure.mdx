## What you will learn

### Technical OSINT

- **Domains:** registration, registrar, nameservers, DNS history, MX records, SPF/DKIM/DMARC, subdomains.
- **IPs:** ASN, BGP, hosting providers, reputation, the limits of geolocation.
- **Certificates:** Certificate Transparency logs, SAN analysis, certificate reuse.

**Tools:** Shodan, Censys, FOFA, VirusTotal, urlscan.io, crt.sh, SecurityTrails.

### Infrastructure pivoting

Finding one suspicious domain is not enough. Learn to pivot:

- Domain → IP → other domains on the same IP.
- Domain → certificate → related domains.
- IP → ASN and hosting provider.
- Favicon hash, HTTP headers or TLS fingerprint (JARM, JA3/JA4) → similar servers.

## Project: infrastructure hunting

Pick a published APT campaign and start from one known domain or IP. Pivot through passive DNS, certificates and hosting, draw an infrastructure graph, and mark which links are confirmed and which are possible. Write it up using what you learned in step 2.

## You are ready to move on when

- Starting from one indicator, you can find related infrastructure on your own.
- Every link in your graph has evidence and a stated confidence.
