## What you will learn

### Understanding CTI

The difference between CTI, threat hunting, incident response, forensics and OSINT. The four levels of intelligence:

- **Strategic:** supports management decisions. Example: is the financial sector in our region increasingly targeted by ransomware groups?
- **Operational:** campaigns and threat actors. Example: an APT campaign targeting banks with phishing and custom malware.
- **Tactical:** the TTPs used in an attack. Example: a group using DLL side-loading for persistence.
- **Technical:** directly usable data: IPs, domains, hashes, YARA rules.

### The lifecycle and requirements

Planning and direction, collection, processing, analysis, dissemination, feedback. Learn to write Priority Intelligence Requirements (PIRs) and break them into collectable questions.

Example PIR: *What APT groups are targeting financial organizations in the Middle East?* Smaller questions: which groups, which malware, what infrastructure, which initial access techniques, which latest campaigns.

### Analysis and confidence

Source reliability, information credibility, confidence levels, intelligence gaps, and Analysis of Competing Hypotheses (ACH). Always separate what you observed from what you assess.

### MITRE ATT&CK

Tactics, techniques, sub-techniques, groups, software and campaigns. Use [ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/) to build a technique layer for a group. One shared technique does not prove two attacks come from the same group.

## Project: map a report

Take one public APT report from a vendor. Write the PIRs it answers, map every behaviour in it to ATT&CK, and build a Navigator layer. Mark which statements in the report are facts and which are assessments.

## You are ready to move on when

- You can turn a business question into PIRs and smaller collectable questions.
- You can map a report to ATT&CK without guessing.
- You can state a judgment with a confidence level and explain why.
